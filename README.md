# ultima-online

Python scripts for [TazUO](https://tazuo.org)'s Legion Scripting engine, in [`legion/`](legion/README.md).

| Script | What it does |
| --- | --- |
| `legion/dist/tame.py` | Target an animal and tame it until it accepts you, then target the next one |
| `legion/dist/buffs.py` | Keeps buffs standing, recasting each as it lapses |
| `legion/dist/mining.py` | Mines the nearest vein and smelts the ore |
| `legion/dist/mine-here.py` | Mines the spot you are standing on until it runs dry |
| `legion/dist/lumberjack.py` | Chops trees, makes boards, loads the pack animals, roaming rather than boxed |
| `legion/dist/arms-lore.py` | Target a weapon and use Arms Lore on it until the skill caps |
| `legion/dist/magery.py` | Trains Magery on the spells that gain without a victim |
| `legion/dist/mysticism.py` | Trains Mysticism from nothing to cap on the five spells that gain without a victim |
| `legion/dist/chivalry.py` | Trains Chivalry, spending tithing points as well as mana |
| `legion/dist/bowcraft.py` | Trains Bowcraft from 40 to cap through the craft gump |

See [legion/README.md](legion/README.md) for the build step, layout, and notes on TazUO's API.
